# Dunmore East Sea Scouts — Marine Weather Dashboard

Live marine weather and launch-safety dashboard for Dunmore East Sea Scouts.

- Current conditions and multi-day forecast tabs
- Open-Meteo (with model selection), MET Norway, and Met Éireann sources
- Per-group launch thresholds, Leaflet harbour map, gear checklist
- Offline caching and 60-second refresh cooldown

App source lives in `dunmore-weather/`. See `dunmore-weather/amplify.yml` for deployment.
